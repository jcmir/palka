# Контракт управления питанием (PowerController Contract)

Документ определяет абстрактный контракт компонента `PowerController`, отвечающего за принудительное завершение работы операционной системы Windows.

## 1. Абстрактный интерфейс `PowerController`

`PowerController` является минимальным абстрактным интерфейсом подсистемы `windows-platform`, инкапсулирующим системные вызовы Windows API для выключения компьютера.

```rust
// Концептуальное представление интерфейса PowerController
trait PowerController: Send + Sync {
    /// Инициировать выключение компьютера через системный вызов Windows
    fn initiate_shutdown(&self) -> Result<(), PowerError>;

    /// Проверить наличие привилегии SeShutdownPrivilege в токене процесса службы
    fn check_privileges(&self) -> Result<(), PowerError>;
}
```

## 2. Нормативные правила и граница авторизации отмены

1. **Граница авторизации отмены (Cancellation Boundary)**:
   * **До наступления дедлайна (`current_remaining > 0`)**: запланированное выключение может быть отменено авторизованной доменной командой `CancelShutdownTimer` (из Telegram или локально через ввод PIN).
   * **В момент или после наступления дедлайна (`current_remaining <= 0`)**: действие переходит в фазу исполнения и **БОЛЕЕ НЕ МОЖЕТ БЫТЬ ОТМЕНЕНО**. Возможность отмены через `CancelShutdownTimer` на этапе выполнения системного вызова отсутствует.
2. **Исполнение в момент дедлайна**:
   * Предупреждения выводятся заблаговременно (60m, 30m, 20m, 10m, 3m).
   * Ровно при наступлении `Deadline` служба `service` вызывает метод `initiate_shutdown()`.
   * Система не вводит искусственных обратных отсчетов после наступления `Deadline`.
3. **Необходимые системные привилегии**:
   * Служба `service` ДОЛЖНА (SHALL) обладать привилегией `SeShutdownPrivilege`.
   * При инициализации служба вызывает `check_privileges()` для валидации прав в токене процесса.

## 3. Обработка ошибок
* При возврате ошибки `PowerError` от системного вызова служба логирует инцидент, переводит статус здоровья в `ServiceHealth::Degraded` и отправляет экстренное уведомление родителям через Telegram.
