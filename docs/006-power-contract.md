# Контракт управления питанием (PowerController Contract)

Документ определяет абстрактный контракт компонента `PowerController`, отвечающего за принудительное завершение работы операционной системы Windows.

## 1. Абстрактный интерфейс `PowerController`

`PowerController` является абстрактным интерфейсом подсистемы `windows-platform`, инкапсулирующим системные вызовы Windows API для управления питанием и завершением работы.

```rust
// Концептуальное представление интерфейса PowerController
trait PowerController: Send + Sync {
    /// Инициировать выключение компьютера через системный вызов Windows
    fn initiate_shutdown(&self) -> Result<(), PowerError>;

    /// Отменить инициированное выключение компьютера
    fn abort_shutdown(&self) -> Result<(), PowerError>;

    /// Проверить наличие необходимых системных привилегий в токене процесса службы
    fn check_privileges(&self) -> Result<(), PowerError>;
}
```

## 2. Нормативные правила и семантика выключения

1. **Исполнение в момент дедлайна**:
   * Пользователь заблаговременно получает серию предупреждающих уведомлений строго на порогах: 60m, 30m, 20m, 10m, 3m до дедлайна.
   * При наступлении `Deadline` служба `service` вызывает метод `initiate_shutdown()` компонента `PowerController`.
   * Контракт не вводит дополнительных обратных отсчетов после наступления `Deadline`.
2. **Отмена запланированного выключения**:
   * До наступления `Deadline` запланированное выключение может быть отменено авторизованной доменной командой `CancelShutdownTimer` (из Telegram или локально через ввод PIN).
   * Если команда отмены поступила во время выполнения системной процедуры завершения, вызывается `abort_shutdown()`, возвращая систему в `ShutdownState::Idle`.
3. **Необходимые системные привилегии**:
   * Служба `service` ДОЛЖНА (SHALL) обладать привилегией `SeShutdownPrivilege`.
   * При инициализации служба вызывает `check_privileges()` для валидации прав в токене процесса.

## 3. Обработка ошибок
* При возврате ошибки `PowerError` от системного вызова служба логирует инцидент, переводит статус здоровья в `ServiceHealth::Degraded` и отправляет экстренное уведомление родителям через Telegram.
