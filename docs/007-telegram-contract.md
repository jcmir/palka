# Контракт интеграции с Telegram (Telegram Contract)

Документ определяет спецификацию удаленного управления и взаимодействия через мессенджер Telegram. Все команды и события соответствуют [Доменному контракту](file:///c:/PALKA/docs/002-domain-contract.md).

## 1. Авторизационный барьер и безопасность

1. **Белый список идентификаторов (Whitelist Authorization)**:
   * Доступ к Telegram-интерфейсу ДОЛЖЕН (SHALL) быть строго ограничен списком разрешенных `ChatId` и `UserId`, зафиксированных в защищенной конфигурации службы.
   * Любые входящие сообщения от неавторизованных `UserId` / `ChatId` ДОЛЖНЫ (SHALL) немедленно и безусловно отбрасываться без выполнения каких-либо действий и без разглашения внутренней информации.
2. **Абсолютный запрет произвольного исполнения (Strict Domain Scope)**:
   * Telegram-адаптер ДОЛЖЕН (SHALL) поддерживать только строго определенный замкнутый перечень доменных команд.
   * **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО**:
     * выполнение произвольных системных команд или консольных утилит;
     * запуск скриптов PowerShell, командной строки CMD или Bash;
     * запуск, чтение, модификация или передача произвольных файлов;
     * запуск или завершение произвольных процессов операционной системы.

## 2. Поддерживаемые удаленные команды (Supported Domain Commands)

Telegram-бот обрабатывает исключительно следующие доменные намерения:

| Команда Telegram | Соответствующая доменная `Command` | Описание |
| :--- | :--- | :--- |
| `/status` | `QueryStatus` | Запрос текущего состояния сети, питания, активных таймеров и здоровья службы |
| `/block <минуты>` | `ScheduleInternetBlock { duration_minutes }` | Планирование блокировки интернета через указанное количество минут |
| `/block_now` | `ImmediateInternetBlock` | Немедленная принудительная блокировка доступа в Интернет |
| `/unblock` | `RestoreInternet` | Немедленное снятие блокировки доступа в Интернет |
| `/cancel_block` | `CancelInternetBlockTimer` | Отмена активного таймера блокировки интернета |
| `/shutdown <минуты>` | `ScheduleShutdown { duration_minutes }` | Планирование выключения компьютера через указанное количество минут |
| `/cancel_shutdown` | `CancelShutdownTimer` | Отмена активного таймера выключения компьютера |
| `/msg <текст>` | `SendParentMessage { text }` | Отправка текстового сообщения ребенку в интерфейс трея |

Любые синтаксически некорректные или нераспознанные команды возвращают подсказку с доступными командами без вызова системных функций.

## 3. Исходящие уведомления родителям (Outbound Notifications)

Служба автоматически отправляет форматированные сообщения в авторизованные Telegram-чаты при наступлении следующих событий:
1. **События предупреждений (`WarningEvent`)**: Уведомление о приближении порога блокировки интернета или выключения (за 60, 30, 20, 10, 3 мин).
2. **Смена состояния сети или питания**: Фиксация факта блокировки, разблокировки или запуска процедуры выключения.
3. **Сообщения от ребенка (`ChatMessage`)**: Доставка текста, отправленного ребенком из трей-приложения.
4. **Критические предупреждения безопасности**: Множественные неудачные попытки ввода локального PIN-кода, ошибки драйвера фильтрации трафика.

## 4. Надежность доставки и работа в офлайне (Offline Resilience)

1. **Очередь исходящих сообщений**:
   * При временном отсутствии интернет-соединения (или при старте службы до установления сетевого линка) исходящие уведомления и сообщения от ребенка буферизуются в энергонезависимой локальной очереди.
   * При восстановлении сетевой связности очередь сообщений гарантированно доставляется в Telegram.
2. **Идемпотентность**:
   * Telegram-адаптер отслеживает `update_id`, исключая повторную обработку дублирующихся вебхуков/поллинг-сообщений.
